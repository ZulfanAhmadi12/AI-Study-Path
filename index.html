A note before you start

I'm really interested in AI, and it often confuses me. Every time I sit down to learn it, the field seems to get bigger: more subfields, more jargon, and something new announced almost every week. It's hard to tell where to start, what to learn next, or even roughly how all the pieces fit together.

So I made the map I wanted to have. If you're new and it feels like too much, that's a normal place to be. I'm there too, some days.

How I'd use it, if it helps:

  1. Get the whole picture first. The nested boxes show how the big words fit together: every LLM is a foundation model, every foundation model is deep learning, and so on. The layers below open each box up.
  2. Pick one path, not everything. asks two questions and suggests one. The hours on a path count every book in full, so you can move on long before you finish them.
  3. Tap a word when it stops you. Words with a dotted underline show a short definition. The has the full list.

About the speed. New models come out every few weeks, and this map won't keep up with all of them. My reading is that most of what's new is built on a small set of older ideas that change slowly, so each layer is marked Stable, Slow-changing or Fast-moving. has a few ways to follow the rest without chasing every headline.

I'm still learning this too, so the levels and hours here are my best guesses. — Zulfan
